# Blog
Blog aplication made with django.

## Requirements
* Python 3
* Django 4
* Git
* HTML
* Bootstrap
* Pillow

## Main features
* User authentication (login, register, and logout) out of the box
* User profile system
* CRUD operations
* Bootstrap 5 static files
* Easy-to-understand forms with validation.
* User communication through a comment system (users can comment on blogs they have read)

## Installation
1. Install the required libraries
```bash
pip install django

pip install Pillow
```

2. Clone the Repository
```bash
git clone https://github.com/xok9ty/dj_project.git
```
3. Set Up a Virtual Environment (Recommended)
```bash
venv\Scripts\activate
```

4. Run Migrations
```bash
python manage.py makemigrations
```
```bash
python manage.py migrate
```

## How to use
1. Start the Server
```bash
python manage.py runserver
```

2. Click the "Register" button and fill out the registration form. Then log in and start using the blog application =)
